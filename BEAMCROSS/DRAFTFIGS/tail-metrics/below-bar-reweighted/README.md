# Reweighted below-bar tail motion: exploratory group and time analysis

Source: `BEAMCROSS/results/tail_reweight_L40_halfdepth_20261109`, the new
post-hoc below-bar weight 1 at the first below-bar row, increasing to 2 by
half-depth and then constant. It uses the saved original L40/S2.5/M2 profiles;
the original measure is retained separately and the code does not modify it.
Each trial's `NewBelowNormalized` is normalized using its own median and MAD.
The normalized measure is an index, not an absolute physical motion amount.
Different trials can have different normalization scales.

For comparability with the earlier tail presentation, the primary exploratory
`Legacy` summary pools all finite normalized frame samples from the available
crossings within each mouse-day, so crossings contribute according to their
number of unmasked frames. All 377 trials contributed; one run mouse has two
rather than three retained D0 crossings. There are 42 mice (12 sedentary, 12
walk, 18 run) and 15 cages (4, 4, 7) at each day, with repeated mice. Full
source filenames, trial/frame counts and invalid counts are preserved in the
trial and mouse-day CSVs. The original tail bad-frame mask is respected, but
443 samples across the dataset are flagged as invalid frame pairs while not
being tail-bad under legacy conventions. The `Strict` sensitivity excludes
those pairs and uses the pre-replacement normalized value; all 377 scales were
finite and positive and there were no unmasked nonfinite pre-replacement values.
`Raw` is a separate descriptive/exploratory summary of `NewBelowRaw` over valid
frame pairs; it is not normalized and is not directly interchangeable with the
within-trial normalized index. Raw image-motion intensity is sensitive to the
measurement setup and can include residual body, paw and background motion.

For each day and for D07−D00 and D14−D00 within-mouse changes, cage means are
analyzed with the earlier exact cage-label permutation procedure within cohort.
Overall tests assess the three groups; pairwise tests use cohort-balanced cage
contrasts. Pairwise p-values are Holm-adjusted across the three pairs separately
within each measure and period. Neither overall nor pairwise p-values are
adjusted across days, change periods or the alternative metrics. This is an
exploratory analysis, not a fully specified repeated-measures model or a
pre-specified family-wise correction across behavioral outcomes. Stratification
by cohort is used for the test; whether randomization was stratified by cohort
is not established.

The D14−D00 normalized overall group p is 0.389; the run−sedentary contrast
has raw p=0.0159 and three-pair Holm p=0.0476. This pairwise result is a
non-gated exploratory contrast and does not overturn the non-significant
omnibus test. The tests use different statistics/permutation distributions:
the omnibus assesses all three groups together, whereas a pairwise test uses
only the two groups and a cohort-balanced difference. Values near 0.05 should
not be treated as proof, particularly with four sedentary cages. Strict-mask
sensitivity gives overall p=0.397 and the same run−sedentary Holm p=0.0476.
The raw weighted signal yields D14−D00 overall p=0.265 and run−sedentary
Holm p=0.286, illustrating that raw and normalized outcomes differ.

`within-group-time-exploratory.csv` contains two-sided exact sign-flip tests of
D07−D00 and D14−D00 cage mean changes within each group, with Holm across the
three groups separately for each period. This is a within-group time analysis,
not a randomized causal test; it assumes cage change distributions are symmetric
about zero under the null. With only four cages per sedentary/walk group, exact
p-values are coarse. Tests are not adjusted across periods or other outcomes.

Files: `below-bar-reweighted-days-and-change` in PNG, FIG, SVG;
`trial-values.csv`, `mouse-day-values.csv`, `descriptive.csv`,
`group-comparisons.csv`, and `within-group-time-exploratory.csv`. Regenerate with
