## Current criteria
No-mouse probability<.85 is historically zeroed. Remove zero-weight column runs<=15 columns by setting probability1, except the run connected to crop column0(mouse-centroid/body side). Preserve all nonzero probabilities and wider exclusions. Square destination-frame probabilities. Below-bar distance weight1→2 at halfdepth then2. Recompute framewise raw below sum and full-profile motion median height. Height receives existing centered5-frame mean within validruns. Raw below scalar receives centered5-frame arithmeticmean BEFORE per-trial median/1.4826MAD normalization; negativez clipped0. Strictz>3.5; closinglength5, minimumcomponent5; peakmotionheight<=+7.5mm. Score=sum(max(z-3.5,0)) within accepted component, nofpsdivision. Windows shrink at validrun ends; no smoothing across invalid gaps. Source masks/nonfinite values preserved through combined validity.

Called 'tail bursts' provisionally because these are below-bar post-mouse motion events, not confirmed anatomical slips or measured momentum. Paw contributions remain possible. Do not infer force/torque/momentum from intensity differences. Criteria were tuned using examples and are exploratory; numerical validation does not establish event-level specificity across all84 crossings.
