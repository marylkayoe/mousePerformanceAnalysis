# D14 last-retained crossing: below-bar tail metrics

42 mice,15 cages; same selected crossing for both panels. Selection=max original TrialNumber among retained D14 trials per mouse, not assumed trial3. Full filenames and trial numbers in mouse_values.csv. Dots=mice, diamonds=cage means, horizontal bars=mouse-group means. Editable standalone and paired SVGs directly use supplied template fonts, marker sizes, colors and axis geometry.

Left=observed downcrossings of five-frame-mean full-profile probability-weighted median motion height through zero (valid nonnegative to valid negative). No minimum duration or hysteresis. Missing gaps not bridged and starts after invalid gaps are not counted. These are below-bar motion-height episodes, not anatomical tail dips. Read from validated parent trial_summary.csv.

Right=peaks in unchanged raw corrected below-bar motion with prominence>=5*1.4826*MAD and separation0.1s. Threshold computed per trial on joint-valid raw/height samples, matching D0 scatter; original masks and gaps preserved. No added smoothing or background subtraction. Within short valid segments, separation is capped just below segment span (at most one interior peak can survive); no joining across gaps. NaN count on nonpositive/invalid scale; all selected counts finite. Peak original frames saved in ../peak-pilot-strict/D14_last_peak_events.csv, counts/thresholds in corresponding counts.csv. Counts not duration-normalized. Different valid exposure times and trial-specific thresholds can influence comparisons. No classification as biological tail dips.

Exploratory raw omnibus exact cage-label permutations within cohort, assuming exchangeability, using established cage_tests.py. Pairwise raw and Holm3 results in statistics.json, not bracketed. No across-outcome correction. Selection and peak thresholds are exploratory/data-informed. No source results changed, no group-effect claim based on visual differences. To reproduce run countD0FirstBelowBarPeaks(14,'last') in MATLAB R2024b, then tests/plotD14LastBelowBarMetrics.py.

Display terminology: "Tail slips" = detected peaks in corrected raw below-bar motion (5-MAD prominence,0.1s separation); "Below-bar motion" = observed negative-motion-height downcrossings. These are operational labels, not confirmed physical slips or anatomical tail position. Figure filenames retain original metric identifiers for compatibility. Labels revised without changing data/statistics.
